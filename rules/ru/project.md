# Проект RepEr

## Конфигурация

- **Конфигурация:** RepEr (Reporter Error), версия 3.2.1.0
- **EDT-проект:** корень репозитория (исходники в `src/`)
- **Доработки:** объекты метаданных с суффиксом `_RepEr` (и связанные `_RepEx`) — кастомная функциональность проекта
- **БСП:** проект использует Библиотеку стандартных подсистем — см. [bsl-ssl.md](bsl-ssl.md)
- **MCP-сервер:** EDT MCP Server (`user-EDT MCP Server`) — чтение/запись BSL и метаданных только через его инструменты
- **Язык общения с пользователем:** русский
